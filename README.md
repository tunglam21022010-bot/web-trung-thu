# 🌕 Trung Thu — Trăng Đoàn Viên

Website Trung Thu bằng HTML/CSS/JavaScript thuần.

## Chạy trên máy

Mở trực tiếp `index.html` bằng trình duyệt.

## Deploy lên Vercel

1. Tạo repository mới trên GitHub.
2. Upload `index.html`, `style.css`, `script.js`.
3. Vào Vercel và chọn **Add New → Project**.
4. Chọn repository GitHub vừa tạo.
5. Framework Preset: **Other** (hoặc để Vercel tự nhận).
6. Build Command: để trống.
7. Output Directory: để trống.
8. Bấm **Deploy**.

Sau khi deploy, Vercel sẽ cấp cho bạn một địa chỉ dạng:

`https://ten-project-cua-ban.vercel.app`
